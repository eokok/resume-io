# Resume.io — 所见即所得简历制作 Web App

一个单文件、零依赖后端、可直接在浏览器打开的简历制作工具。左右分屏：左侧表单编辑，右侧实时预览 A4 简历，支持 6 种模板风格一键切换，并可在浏览器内直接生成高质量 PDF。

## 功能

- 🖥️ 左右分屏：左侧编辑区（个人信息 / 教育 / 工作 / 项目 / 技能 / 荣誉 / 自我评价 / 自定义模块），右侧实时预览 A4 纸张效果
- 🎨 6 种模板风格：极简黑白、商务蓝、设计师彩色、学术衬线、清新绿意、双栏创意
- ➕ 模块可自由添加 / 删除，支持完全自定义标题的模块
- 💡 编辑时修改的字段会短暂高亮提示
- 📄 客户端生成 PDF（jsPDF + html2canvas），约 265 DPI 清晰度，文件体积小（0.6MB 左右）
- 🔗 顶部「分享链接」可生成只读预览链接

## 运行方式

直接用浏览器打开 `index.html` 即可，无需安装任何环境、无需服务器。

PDF 生成依赖 `html2canvas.min.js` 与 `jspdf.umd.min.js`，已随仓库提供，离线可用。

## 目录结构

```
resume-io/
├── index.html          # 应用本体（含全部样式与逻辑）
├── html2canvas.min.js  # 截图渲染依赖
├── jspdf.umd.min.js    # PDF 生成依赖
└── README.md
```
